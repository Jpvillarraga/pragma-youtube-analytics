
# Análisis de tendencias de videos YouTube en Estados Unidos

## Descripción
Proyecto desarrollado como solución
al reto técnico de Pragma.

El objetivo es analizar los videos en tendencia de YouTube
en Estados Unidos, identificar patrones de interacción y
desarrollar modelos predictivos que apoyen la toma de
decisiones estratégicas.

## Metodología
Se utiliza CRISP-DM como metodología de trabajo:

1. Comprensión del negocio.
2. Comprensión de los datos.
3. Preparación de los datos.
4. Modelamiento.
5. Evaluación.
6. Presentación de resultados.

## Estructura del proyecto

- data/: datos originales y preparados.
- notebooks/: análisis exploratorio y modelamiento.
- reports/: presentación ejecutiva.

## Fuente de datos
YouTube Trending Video Dataset (Kaggle):
https://www.kaggle.com/datasets/datasnaek/youtube-new

Se utilizan los archivos correspondientes a Estados Unidos.

## Tecnologías
Python 3.11, Pandas, NumPy, Scikit-learn,
Matplotlib, Seaborn y SciPy.
